# Anime Explorer

A web application that allows users to search for anime and view information using the Jikan API.

## Features

- Search for anime by name
- Display anime posters
- View ratings and episode counts
- Responsive design
- Loading animation while fetching data

## Technologies Used

- HTML
- CSS
- JavaScript
- Fetch API
- Jikan API

## How to Run

1. Clone the repository

```bash
git clone <repo-url>
```

2. Open the project folder

3. Open `index.html` in your browser
